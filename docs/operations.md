# Управление сервисом

Команда `/admin` работает в личном чате бота для Telegram ID из `ADMIN_IDS`. Изменения цены, доступов, возвраты, коммуникации с пользователем, рассылки и настройки подтверждаются отдельной кнопкой. Подтверждение действует десять минут. Действия записываются в журнал PostgreSQL.

| Задача | Команда и пример |
|---|---|
| Установить цену | `/price 250` |
| Описание счёта | `/description Доступ к терминалу на 30 дней` |
| Продажи | `/plan on`, `/plan off`, `/plan manual`, `/plan automatic` |
| Временная цена на сутки | `/discount 200 24` |
| Ожидающие заявки | `/orders`, затем кнопка решения и подтверждение |
| Найти пользователя | `/user 12345` или `/user @example` |
| Выдать доступ | Кнопка «Выдать доступ» или `/grant 12345 7d Причина` |
| Бессрочный доступ | `/grant 12345 forever Причина` |
| Пригласить нового пользователя | `/invite 14`, ссылка на 14 дней для одной активации, действительна 7 дней |
| Управление доступом | `/access 12345 freeze`, `unfreeze`, `revoke`, `block`, `unblock` |
| Написать от имени бота | `/dm 12345 Сообщение` |
| Вернуть Stars | `/refund UUID_ЗАКАЗА` |
| Статистика | `/stats 1`, `/stats 7`, `/stats 30`, `/stats 0 csv` |
| Ежедневный отчёт в 09:00 UTC | `/report 9`, отключение через `/report off` |
| Поддержка | `/tickets`, кнопка обращения, `/reply НОМЕР Ответ`, `/close_ticket НОМЕР` |
| Промокод на 10% | `/promocreate PROMO10 percent 10 30 100 1 1` |
| Промокод на семь бесплатных дней | `/promocreate GIFT7 days 7 30 100 1 0` |
| Управление промокодами | `/promolist`, `/promotoggle PROMO10 off` |
| Отложенная рассылка | `/broadcast active 60 Текст объявления` |
| Кнопка в рассылке | `/broadcast all 0 Текст | Подробнее | https://example.org` |
| Доставка и отмена | `/bstats`, `/bcancel 42` |
| Эмодзи | `/emoji` с кастомным эмодзи, `/emojiset gift` с эмодзи в том же сообщении |
| Состояние | `/server`, журнал контейнера и `GET /health` |

Пользователь применяет скидочный код командой `/buy КОД`, бесплатный код командой `/promo КОД`. В рассылку попадают подписчики, давшие согласие в профиле. Команда `/unsubscribe` отзывает согласие. Для фото и видео укажите команду в подписи к вложению. Отправьте предпросмотр владельцу до подтверждения.

Настройте комиссии на основании актуальных условий конкретной площадки. Поля `buy_fee` и `sell_fee` задаются долями. Расходы `transfer`, `network`, `conversion`, `extra_sell` задаются в валюте расчёта. Ниже пример формата с тестовыми числами.

```text
/fees Portals {"buy_fee":"0","sell_fee":"0.05","transfer":"0.3","network":"0.1","conversion":"0.02","extra_sell":"0"}
/rate GRAM TON 0.30 Название источника
/legal {"owner":"Реквизиты оператора и контакт","terms":"Условия продажи и возврата","privacy":"Политика конфиденциальности","risk":"Риски ручной торговли"}
```

Курс в примере синтетический. Укажите наблюдаемый курс и источник. Курс для сравнения с капиталом пользователя применяется в течение 24 часов. При отсутствии свежего курса сигналы в другой валюте не проходят фильтр капитала в TON.

## Платежи и сопровождение

Заявка хранит цену и описание на момент создания. `pre_checkout_query` проверяет владельца, сумму и валюту счета. Подписка активируется после `successful_payment`. Платёж и доступ проходят одной транзакцией PostgreSQL. Повторный идентификатор платежа распознаётся по уникальному ограничению. Возврат учитывается отдельно, соответствующий период доступа отзывается. Подарочная выдача хранится в `access_grants`. Выручка Stars означает сумму финансовых операций в Stars за период.

Для поддержки хранятся текст и Telegram file ID. Файлы пересылаются через платформу, контейнер не загружает и не исполняет содержимое вложений. Удаление профиля очищает пользовательские данные приложения, портфели, настройки и обращения. Идентификаторы в финансовых записях и аудите сохраняются для разбирательств и учёта. Сроки хранения и порядок обработки запросов нужно указать в политике владельца.

Состояние доставки Telegram после сбоя может быть неопределённым. Очередь повторяет временные ошибки, учитывает RetryAfter и прекращает дальнейшую рассылку после блокировки бота. Дедупликация записей защищает от постановки одного сигнала в очередь повторно.
